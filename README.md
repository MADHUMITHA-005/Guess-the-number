# Guess the Number 

A simple and interactive number-guessing game built using HTML, CSS, and JavaScript.

## About the Project

Guess the Number is a browser-based game where players try to guess a randomly generated number. The project helped me practice frontend development and JavaScript fundamentals.

## Features

* Random Number Generation: Generates a random number for the player to guess.
* User Input: Allows players to enter their guesses.
* Interactive Feedback: Provides feedback to help players guess the correct number.
* Simple Interface: Easy-to-use interface built with HTML and CSS.

## Technologies Used

* HTML5
* CSS3
* JavaScript

## What I Learned

* Structuring a webpage using HTML.
* Styling the interface using CSS.
* Using JavaScript for game logic and user interactions.
* Working with random number generation and conditional statements.

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your browser.
4. Start guessing!
